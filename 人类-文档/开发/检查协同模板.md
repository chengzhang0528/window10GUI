# 检查协同模板

用于确认当前模板的文档控制面可被新项目安全采用。

1. 在 `coder_driver` 根目录运行：

   ```powershell
   npm run check:docs
   ```

   命令退出码为 `0` 表示文档结构、任务边界、工作流和人类入口通过校验。

2. 接入实际项目时，先在根 `AGENTS.md` 写入已验证的源码根和项目路由，再在 `文档/WORKSPACE_STRUCTURE.md` 声明该项目需要的精确文档位置。

3. 只有已有产品、设计、决策、运行或可恢复任务事实时，才创建对应文档；随后再次运行 `npm run check:docs`。
