# Windows Agent CLI

面向 Windows 10 交互式桌面的 Agent GUI 操作 CLI（内部代号 DeskPilot）。当前实现采用类似 Feishu CLI 的标准输入输出 JSON/NDJSON；Feishu CLI 仅是接入形态参考，本项目与其无依赖或隶属关系，也不使用 MCP Server。核心代码和可直接执行的构建、Chrome 验证步骤位于 [Windows Agent CLI 开发与验证](src/WindowsAgent.Cli/README.md)。
