Owner: 项目维护者

Depends On:

- ../../.agents/skills/release-deployment/SKILL.md

## Trigger

用户明确授权发布正式包、部署已准入制品、执行目标环境迁移、上线、切换或回滚。

## Input

独立 Deployment 任务、Artifact、Target、显式授权、系统测试或豁免准入证据、命中 Runbook、Rollback 和部署后最小检查。

## Output

该 Artifact 在该 Target 的部署成功、回滚成功、失败或受阻结论，以及可核验的目标状态；不产生源码修复或系统测试结论。

## Actions

`ACT-CLASSIFY-REQUEST` → `ACT-CLASSIFY-EXECUTION-TYPE` → `ACT-REGISTER-TASK` → `ACT-ROUTE-CONTEXT` → `ACT-OPEN-DEPLOYMENT-PLAN` → `ACT-VERIFY-BASELINE` → `ACT-AUTHORIZE-DEPLOYMENT` → `ACT-EXECUTE-DEPLOYMENT` → `ACT-VERIFY-RESULT` → WF-0004。发现产品缺陷或新需求时先阻断，获得用户修复授权后另建 WF-0002；证据不足只阻断当前部署，只有用户另行要求测试时才建立 WF-0005。

## Key Constraints

- Deployment 始终受控；只有确定 Artifact、Target 和当前用户授权后才能创建 DeploymentPlan，计划为 `Active` 前还必须绑定 Rollback 和准入证据。
- 只部署计划中的同一制品，不从当前工作树临时构建替换，不修改产品源码，不夹带功能修复。
- 具体命令、凭据键、迁移、切换、检查和恢复只从目标项目 Runbook 获取；不凭经验补全。
- 部署后只执行证明目标变更生效和决定是否回滚的最小检查；不得扩张成系统级大范围回归。
- 失败时优先停止或按授权回滚，保留可诊断证据；不得现场修改代码继续部署。

## Stop When

Artifact、Target、授权、准入证据或 Rollback 任一缺失，计划仍为 Draft，目标状态与基线冲突，出现未授权数据风险，或继续需要修改源码、替换制品或扩大系统测试时停止。
