# WF-0003 调查与阻断

Depends On:
- WORKFLOW_CONTRACT.md

## Trigger

用户要求只读调查、诊断或评审，或者当前任务因外部依赖、缺失权限、事实冲突或验证失败而无法继续，并可能跨会话保留。

## Input

问题描述、来源任务类型、当前任务、可读取证据、允许的诊断边界、已尝试路径和下一步所需条件。

## Output

有证据支持的结论、明确未知项和建议；若阻断跨会话，则同步总控并创建或更新唯一 Issue。未获得实现授权时不产生修复性工作空间变更。

## Actions

`ACT-CLASSIFY-REQUEST` → `ACT-CLASSIFY-EXECUTION-TYPE` → `ACT-ROUTE-CONTEXT` → `ACT-VERIFY-BASELINE` → `ACT-VERIFY-RESULT`；跨会话阻断再执行 `ACT-REGISTER-TASK` 和 `ACT-CAPTURE-BLOCKER`。获得实施授权后根据用户的新任务目标选择 Development、SystemTest 或 Deployment 及对应主 Workflow。

## Key Constraints

- 诊断不自动授权修复、外部写操作、权限申请或范围扩张。
- 临时错误、命令输出、日志堆积和聊天过程不创建 Issue。
- Issue 只保存恢复任务所需的当前证据、影响、边界和下一入口。
- 调查不改变来源任务的执行类型，也不能用诊断结果自动授权缺陷修复、系统测试或部署；发现 Bug 或新需求时等待或建立独立 Development 任务。

## Stop When

证据不足但继续需要破坏性动作、新权限、秘密、外部协调或用户选择时停止并报告阻断；不得用推测填补结论。
